# Countdown Timer App

A beautiful, responsive countdown timer application built with HTML, CSS, and JavaScript.

## Features

- Set custom countdown target date and time
- Real-time countdown display (days, hours, minutes, seconds)
- Responsive design that works on all devices
- Beautiful gradient UI with smooth animations
- Completion notification when countdown reaches zero

## How to Use

1. Open `index.html` in your web browser
2. Select your target date and time using the date picker
3. Click "Start Countdown" to begin
4. Watch the countdown update in real-time!

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and animations
- `script.js` - Countdown logic and functionality

## Browser Compatibility

Works in all modern browsers that support:
- HTML5
- CSS3
- ES6 JavaScript

## Customization

You can easily customize:
- Colors in `style.css` (gradient values)
- Default countdown duration in `script.js`
- Layout and styling to match your preferences

Enjoy your countdown! 🎉
